# Teardown VR 2.0

A community VR mod for Teardown, built on Nahu's original work and continued with AI-assisted development. The goal is simple: bring this long-awaited project back for everyone to enjoy, with a free release.

> **Project status:** The mod download and source code are planned for a later update. The instructions below describe the intended mod package; this README is not the mod download.

## The story behind the mod

Hey guys! First, sorry for the delay. Work kept me busy, a family matter came up, and then I got sick. It's taken a while to get here, and I appreciate your patience.

Before anything else, **this project would not be possible without Nahu**, who created the original mod. I knew them for a little while before they stepped away and left it unfinished. That was disappointing, of course, but completely understandable. A mod like this is incredibly difficult to make, and I don't blame them at all for deciding not to continue.

The groundwork Nahu put down made it possible to move this project forward. They deserve a huge thank-you and full credit for getting it started.

### Why I kept trying

Just so everyone knows, I'm not a coder or a modder. I don't plan to make mods like this regularly, but I'll do my best to keep this one updated. I've wanted to play Teardown in VR since 2021, and I've been trying to get this project made since 2022. Keeping it working as Teardown changes is the goal, rather than a promise that every new update will work immediately.

I tried working with people to get the mod finished and spent a lot of money along the way. Unfortunately, those attempts led to delays, unanswered messages, prices I couldn't justify, and experiences where I felt scammed.

At the start of this year, I tried again through Fiverr, Freelancer, and other websites. Months went by without the results I was hoping for. I was getting close to giving up.

### How AI became part of the project

I want to be upfront: **AI was used to help continue and fix this mod, but the original work was made by Nahu.** AI did not create that foundation.

A few months ago, I came across videos about ChatGPT and Claude. I tried Claude first, because ChatGPT didn't have the features I needed at the time, but it didn't work out for me then. I kept trying with someone I'd hired, yet more time and money passed with no real progress.

Then I saw a video about ChatGPT Astra and its ability to control a PC and carry out tasks. I was interested, but also hesitant. I had plenty of questions about whether I could trust it and what access to my computer would mean. Eventually, I bought a month's subscription and spent weeks trying it out, from coding tasks to animations.

One of those experiments was making animations for my VRChat character. It was fun watching the tool put things together. The results weren't always perfect, but they impressed me enough to try the real test: getting this old Teardown VR mod working again.

I honestly didn't know whether it would be possible. Using AI was a gamble, but it helped me get the project working in my own testing after years of trying to get it made.

I know people have different views on AI, and I share some of those concerns. For me, this was a practical use of it as a tool: helping finish and repair an existing mod that I'd spent years trying to revive, with the aim of bringing something fun to the community.

### A free project for the community

I intend to release this mod **for free—not a single dime**. I've wanted it to be something the community could enjoy together for a long time.

I also plan to share the source code alongside the mod download so people can see how it works. Those files and the terms for using or modifying them still need to be added; this README does not announce a source-code release or grant a license.

I'd love to see people build on the project once those details are in place. Please give credit to Nahu's original work and this repository when discussing or sharing the project.

It's been a long time coming. Welcome to **Teardown VR 2.0**—I hope you enjoy it!

## Installation

These steps apply to the mod ZIP once it is available.

1. Download the **mod ZIP**.
2. Extract it to a location of your choice, such as a folder on your desktop.
3. Open the extracted folder.
4. Run the included **Install Teardown VR** installer.

The package is intended to provide a one-click installation.

### Optional gun pack

The optional gun pack described for this project requires a separate download from the Teardown Steam Workshop. Its exact Workshop name and link will be added once confirmed.

## Performance settings

Before you start playing:

1. Open the folder where you extracted the mod.
2. Run `performance.bat`.
3. Choose a VR performance option and test which setting works best for your setup.

**Exit Teardown completely before changing the performance setting each time.** Restart the game to test another option.

## How to play

The startup order matters:

1. **Start Teardown first.**
2. Select the mods you want to use and load a map.
3. Wait until the map has fully loaded and the game is running.
4. Open the folder where you extracted the VR mod.
5. Start **SteamVR**.
6. Run **Enable VR**, only after the map is loaded and SteamVR is running.

The game may briefly freeze while VR activates, and the image on your monitor should change. Once the game resumes, you should be ready to play.

## Uninstall

Run the included **one-click uninstall file**.

It is intended to remove the VR mod and the additional files installed with it, including the bundled weapon-pack components. A separate Steam Workshop subscription is managed through Steam.

## Feedback and community

I'd love to see the Teardown community come up with creative VR mods for the Workshop and help this project improve.

Ideas, suggestions, bug reports, and help understanding things that aren't working are all welcome. You can share them through this repository's [Issues page](https://github.com/StrainZex/Teardown-VR/issues).

When reporting a problem, please include:

- Your Teardown version and VR headset.
- The performance option you selected.
- The other mods you had enabled.
- What happened and the steps that led to it.

I'm not an experienced developer, so I can't promise a fix for every issue or an immediate update. I'll do my best, and help from the community would mean a lot.
